# DeterministicAI

A dated public declaration about Grounded DI's Deterministic Intelligence Architecture (DIA).

## Preserved artifact

[`Scroll_161_Public_OpMode_Grounded_DI_Deterministic_AI.pdf`](Scroll_161_Public_OpMode_Grounded_DI_Deterministic_AI.pdf) is a public operational-mode declaration. Its embedded record identifies 2 July 2025 as the first public declaration. The document states Tier 16, `ΔH = 0.0042`, and `Public Use Mode Active`, and says the architecture has operated in legal, environmental, and scientific domains.

## What the repository demonstrates

The repository preserves those source-declared statements in a dated PDF. It contains the README and the PDF, but no implementation, measurements, run logs, benchmark, or replay certificate that independently reproduces the declared operating status or `ΔH` value. The `ΔH` and reproducibility statements are declarations in the document, not measured results in this repository.
