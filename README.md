# DeterministicAI

A dated public provenance record for Grounded DI's Deterministic Intelligence Architecture (DIA).

## Preserved artifact

[Scroll_161_Public_OpMode_Grounded_DI_Deterministic_AI.pdf](Scroll_161_Public_OpMode_Grounded_DI_Deterministic_AI.pdf) is the preserved operational-mode declaration. Its embedded record identifies 2 July 2025 as the first public declaration. The document records Tier 16, ΔH = 0.0042, and Public Use Mode Active, and describes the architecture's use across legal, environmental, and scientific domains.

The artifact remains useful for establishing authorship, terminology, chronology, and the public operating-mode framing in effect at that time.

## Repository scope

This repository preserves the dated declaration and its public provenance. It is intentionally a compact historical archive containing the README and source PDF; it is not intended to be a complete implementation snapshot.

Current implementation, testing, replay, and certificate materials are maintained separately where applicable in the broader Grounded DI development record. Questions about current runtime behavior, measured entropy, or independent verification should be evaluated against the corresponding implementation and evidence artifacts rather than this historical declaration alone.
